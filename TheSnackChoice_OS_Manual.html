Operating Cadence

The rhythm. Workflows bind to these triggers.

CadenceTriggerPurposeRoutines
dailyevery operating dayKeep machines full and faults short-lived; nothing should fester a day.
  • Check telemetry dashboard for faults / sold-out flags (5 min).
  • Triage any fault incident -> playbook fault-triage.
  • Confirm tomorrow's route if any machine is below restock trigger.
weeklyMonday morningClose the prior week, read the one number, decide the week.
  • Run weekly-review workflow (scorecard -> KPIs -> flags -> decisions).
  • Plan + run restock routes (route.py, clustered).
  • Reconcile cash collected vs telemetry (cash-reconciliation playbook).
  • Place supplier order for the week (reorder.py -> supplier-reorder playbook).
monthlyfirst Monday of the monthPerformance gate — keep / fix / cut sites and products.
  • Run monthly-gate workflow.
  • Review per-site revenue/operator-hour; apply site keep/fix/cut policy.
  • Review per-SKU performance; apply product-cut policy (when data exists).
  • Review open incidents and spikes; discharge any that have enough data.
quarterlyfirst week of the quarterStrategy + capital allocation.
  • Review north-star trend across the quarter.
  • Apply machine-buy policy: deploy capital where demand is constrained.
  • Re-scout pipeline (Location Tracker) for next sites.
  • Re-read ASSUMPTIONS.md; promote discharged spikes into config.
